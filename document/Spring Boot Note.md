## Spring Boot Versions with Java versions

- Java LTS: https://www.oracle.com/java/technologies/java-se-support-roadmap.html
- Gradle: https://docs.gradle.org/current/userguide/compatibility.html
- Spring boot LTS: https://endoflife.date/spring-boot or https://versionlog.com/spring-boot/

| Spring Boot Version | Java Version | 
|---------------------|--------------|
| 2.7.x               | 8            |
| 3.5.10              | 21           |


- How to check another version use with spring boot and java?
  - Search Library Dependency version have support for java version or spring boot version.
  - Example: do jjwt 0.9.1 have support for java 11?
